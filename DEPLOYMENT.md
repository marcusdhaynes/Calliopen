# Calliopen

The original AI Studio components, styles and assets are retained. The web app is published at https://marcusdhaynes.github.io/Calliopen/.

## Platforms

The manual Native builds workflow builds Windows, macOS, Linux and Android packages using the same web interface. iOS source can be generated with npm run ios:init on macOS; device distribution requires Apple signing. Native packages are unsigned development builds, not app-store releases.

## Services

Firebase authentication and data services remain in the original Firebase project. marcusdhaynes.github.io is now authorized for Google sign-in.
